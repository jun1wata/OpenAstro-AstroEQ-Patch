# OpenAstro-AstroEQ-Patch
Unofficial AstroEQ Support Patch for OpenAstro AlpacaBridge

This repository provides an unofficial AstroEQ support patch for OpenAstro AlpacaBridge.

It is not an official OpenAstro release.

Upstream project:
https://github.com/open-astro/AlpacaBridge

## Target OpenAstro Image

This patch is intended for the **OpenAstro image for ZWO ASIAIR Pro v1.0.0** distributed from:

https://github.com/open-astro/openastro-zwo-asiar-pro/releases

Install the OpenAstro image from the release page onto a separate microSD card, boot the ASIAIR Pro from that card, and then apply this AstroEQ patch to the OpenAstro installation.

Do not apply this patch directly to the original ZWO ASIAIR system.

# Download
Please download `OpenAstro_AstroEQ_public_release.zip` from the **Releases** section.
